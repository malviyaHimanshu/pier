# Code of Conduct

This project follows a simple standard: be respectful, constructive, and specific.

## Expected Behavior

- Be respectful in issues, PRs, and reviews
- Focus on technical content and reproducible facts
- Assume good intent while giving direct feedback

## Unacceptable Behavior

- Harassment, abuse, or personal attacks
- Discriminatory language or behavior
- Repeated bad-faith disruption of discussions

## Enforcement

Project maintainers may moderate comments/issues/PRs and remove content that violates this code of conduct.
